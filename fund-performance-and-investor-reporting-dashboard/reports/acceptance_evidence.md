# Acceptance Criteria Evidence Matrix (`plan.md` Section 6)

| # | Acceptance Criterion | Status | Implementation & Verification Evidence |
|---|---|---|---|
| 1 | Returns and NAV reconcile with approved ledger snapshots. | Verified | `validate_nav_snapshot` & `validate_nav_series_continuity` enforce exact NAV bridge (`closing_nav == opening_nav + net_cf + gross_pnl - fees`) and roll-forward continuity. Verified in `test_domain_and_validation.py`, `test_metrics_hand_calculated.py`, `test_scenario_01_cash_subscription_redemption`, and `reports/validation_report.md`. |
| 2 | Each report discloses methodology and data status. | Verified | `AnalyticsEngine.build_disclosure` embeds `methodology_version`, `data_status`, `environment`, fee basis, currency basis, and audit status into every API payload and JSON/HTML/CSV/Markdown export. |
| 3 | Metrics with inadequate history are flagged. | Verified | Configurable observation thresholds in `config/default_config.json` emit `MetricFlag(INADEQUATE_HISTORY)` on short series (`test_hand_calculated_fixture_exact_match`). Zero-volatility ratios return `None` with `ZERO_VOLATILITY` flags (`test_scenario_03_zero_volatility`). |
| 4 | Simulated performance is visibly labeled. | Verified | Prominent disclosure banner (`SIMULATED / SYNTHETIC DATA — NOT LIVE OR AUDITED TRACK RECORD`) renders in dashboard UI, HTML/Markdown/CSV/JSON exports, and `SIMULATED_DATA` flags; `data_status=AUDITED` is rejected for `SIMULATED`/`PAPER`. |
| 5 | Published reports have immutable version IDs. | Verified | Content-addressed `version_id` (`<series>-v<rev>-<sha256[:8]>`) and SHA-256 digest; `SqliteRepository.update_report` and `ReportWorkflowService` block in-place mutation (`ImmutableReportError`). Verified in `test_scenario_05_report_revision`. |
| 6 | A clean checkout can run the documented setup, tests and demo with permitted fixtures. | Verified | Zero third-party runtime dependencies; `./scripts/reproduce.sh` runs `setup.sh`, `validate.sh`, and `demo.sh` offline against synthetic fixtures (`data/fixtures/manifest.json`). |
| 7 | Architecture, dependency assumptions, known limitations and runbook are committed. | Verified | Committed in `README.md`, `docs/architecture.md`, `docs/ADRs.md`, `docs/assumptions_and_methodology.md`, `docs/api_and_schema.md`, `docs/runbook.md`, and `docs/unsupported_features.md`. |
| 8 | Relevant CI checks pass and raw evaluation or test evidence is retained. | Verified | `./scripts/validate.sh` executes all unit, integration, and 7 required scenario tests and writes retained evidence to `reports/validation_report.json` and `reports/validation_report.md`. |
| 9 | Security, data licensing, IP and any deployment approval requirements are reviewed. | Verified | RBAC + dual control + audit log enforced (`test_scenario_07_unauthorized_access`), order execution permanently disabled (`order_execution_enabled: false`), no external personal repo code copied (clean adapter contracts per ADR-002), synthetic fixtures documented in `data/fixtures/manifest.json`. |
